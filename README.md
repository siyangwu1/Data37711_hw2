# DATA 37711 — Homework 2 code

Each problem is a Jupyter notebook in `code/`, saved with its outputs. The matching `.py` file next to each notebook is an export of its cells.

| File | Contents |
|---|---|
| `code/problem1.ipynb` | 1(c) MLP for the conditional mean and standard deviation of NYC taxi trip durations; 1(e) evaluation of P(Y < 45) |
| `code/problem2.ipynb` | 2(a) cardinality and split; 2(b) target encoding + boosted trees; 2(c) embedding network; 2(d) combined model; 2(e) analysis |
| `code/problem3.ipynb` | 3(a) data plot; 3(b) Random Kitchen Sinks sweep; 3(c) one-hidden-layer MLP sweep; 3(d) comparison, test predictions and fitted surfaces |
| `code/models.py` | `RandomKitchenSinks`, `MLP` and the sweep helpers (starter code, filled in) |
| `code/dataloader.py`, `code/plotting.py` | provided starter code |
| `figures/` | plots generated by `problem3.ipynb` |
| `rks_test_predictions.csv`, `mlp_test_predictions.csv` | 3(d) predictions on `test.csv`: one per row, no header, same order as `test.csv` |

## Running

The data files are not included. Put them in `data/` next to `code/`:

```
data/taxi_trips.parquet
data/retail.csv
data/train (3).csv
data/val.csv
data/test.csv
```

Then run each notebook from the `code/` folder. Paths in the notebooks are relative to it, e.g. `../data/retail.csv`. Requirements: Python 3.12, numpy, pandas, pyarrow, scipy, scikit-learn ≥ 1.3 (for `TargetEncoder`), matplotlib and PyTorch. Everything runs on CPU in a few minutes. Random seeds are fixed, so the results are reproducible.
